# SIM-SPPD v1.0 — Frontend
Frontend statis untuk GitHub Pages. Backend Google Apps Script dipisahkan.

## Sebelum deploy
1. Deploy `Kode.gs` sebagai Web App.
2. Salin URL `/exec`.
3. Buka `js/config.js` dan ganti `PASTE_URL_GAS_EXEC_DI_SINI`.
4. Pastikan `index.html` berada di root folder ini.
5. Jalankan Git dari folder ini, bukan dari folder induk.

Login awal setelah `setupAppEnvironment()`:
- Email: `admin@puspahiang.desa.id`
- Password: `User1234`

Ganti kredensial setelah pengujian awal.
